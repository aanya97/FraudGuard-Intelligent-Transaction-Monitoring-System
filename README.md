## 🚀 Overview

This project combines **Machine Learning and Full-Stack Development** to detect unusual transaction patterns. Transaction data is processed through the application and analyzed using an **Isolation Forest model** to identify potential anomalies.

## ✨ Key Features

- ⚛️ Interactive and responsive frontend built with **React**
- 🟢 RESTful backend API built with **Node.js and Express**
- 🤖 ML-powered anomaly detection using **Isolation Forest**
- 🔗 API-based communication between frontend, backend, and ML service
- 🔍 Detection and classification of suspicious transaction patterns
- 📊 Exploratory data analysis and transaction visualizations

## 🛠️ Tech Stack

| Layer | Technologies |
|-------|-------------|
| **Frontend** | React, Vite, JavaScript, CSS |
| **Backend** | Node.js, Express.js |
| **Machine Learning** | Python, Scikit-learn, Isolation Forest |
| **Data Processing** | Pandas, NumPy |
